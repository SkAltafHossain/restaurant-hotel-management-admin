Admin Panel Prompt

# Role & Context
You are an expert Laravel Backend Developer. Generate a comprehensive, secure, and modular Admin Panel module for a combined "Restaurant and Hotel Management System" using Laravel (latest version) and Tailwind CSS / Blade (or Livewire).

## Core Requirements & Features to Build:
1. **Dashboard & Analytics:** Total revenue charts (food vs. rooms), active room occupancy rate, live online food orders, and quick stats.
2. **Category Management:** Nested categories for restaurant menus (e.g., Starters > Veg) and hotel rooms (e.g., Deluxe > Single/Double) with image uploads and status toggles.
3. **Inventory Management:** Stock tracking for raw kitchen materials and hotel supplies. Set low-stock alerts, track suppliers, and log stock-in/stock-out transactions.
4. **Banner & Promotional Management:** Dynamic promotional sliders, announcement tickers, and banner uploads for both the website homepage and mobile app.
5. **Offline Billing System (POS):** A lightning-fast POS screen for cashiers to generate physical/thermal receipts, handle dine-in/takeaway bills, apply custom discounts, split bills, and record payments (Cash, UPI, Card).
6. **Online Food Order & Table Booking Control:** Real-time management view for incoming web/app food orders (Pending, Preparing, Out for Delivery, Completed) and table reservation requests (Accept/Reject, Table Assignment).
7. **Room Booking Management:** Check-in/check-out workflow, room availability calendar grid, guest identity documentation logs, and billing settlement.
8. **Staff Management:** Role-based access control (RBAC) using Spatie Laravel-Permission (Roles: Admin, Manager, Receptionist, Waiter, Kitchen Chef, Delivery Boy), activity logs, and shift tracking.
9. **[Added Idea] Automated Expense & Multi-Outlet Report Generator:** Daily financial ledger closing, automated PDF/Excel report exports (using Laravel Excel), and tax calculation summaries (GST/VAT).

## Deliverables Needed:
- Database Migrations & Eloquent Models with exact relationships (`hasMany`, `belongsTo`, etc.).
- Resource Controllers with Form Request validation rules.
- Blade/Livewire views matching modern UI guidelines.
